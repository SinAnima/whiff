# File formats

whiff extracts metadata from the **658 formats** below (a build with every feature). Formats it does not list are still identified by signature and get the universal sections (identification, system, temporal, security, physical, integrity).

The **Feature** column is the Cargo feature that enables a format; `common` is on by default. *Unreleased* formats are on `main` but not in the latest release (v0.6.0). [`docs/metadata-extracted.md`](docs/metadata-extracted.md) lists every format planned and what is extracted from each; [`docs/known-gaps.md`](docs/known-gaps.md) lists what is deliberately left out.

Generated by `scripts/file_formats.py` from `whiff formats --json` and `data/families.tsv`.
