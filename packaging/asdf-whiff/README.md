# asdf-whiff

asdf plugin that installs `whiff` from [GitHub Releases](https://github.com/SinAnima/whiff/releases).

```bash
asdf plugin add whiff https://github.com/SinAnima/asdf-whiff.git
asdf install whiff 0.8.0
asdf global whiff 0.8.0
whiff --version
```

Publish this directory to `SinAnima/asdf-whiff` (or keep developing from the monorepo path).
